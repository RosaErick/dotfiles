# Hyprland Desktop

`packages/desktops/hyprland/` groups the compositor, Waybar, Rofi, Mako, dock,
scripts, and services. This is a Linux desktop configuration; Arch installation
packages are kept separately in `bootstrap/arch/`.

| Shortcut | Action |
|---|---|
| `Super + /` | Search shortcuts, read from `hyprland.lua` |
| `Super + Q` | Terminal |
| `Super + R` | Launcher |
| `Super + E` | Yazi |
| `Super + Shift + E` | Nautilus |
| `Ctrl + Alt + Delete` | Session menu |

## Scripts

Installed in `~/.scripts/`, accessible to shells, Hyprland, and services:

- `wallpaper`: choose an image, monitor, and fit mode.
- `cheatsheet`: look up shortcuts.
- `audio-device`: choose audio input/output.
- `powermenu`, `screenshot`: session controls and screen capture.
- `files`, `taskmanager`, `dock`: launch desktop applications.
- `waybar-fullscreen`: hide the bar in fullscreen.
- `desktop-services`: explicitly enable user services.
- `sddm-install`: copy the login theme to the system; uses sudo.

Monitor and workspace settings generated by nwg-displays, the selected wallpaper,
and per-monitor state stay local. Use `nwg-displays` and `wallpaper` when setting
up a machine for the first time.
